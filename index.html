🗺️ マップ操作

  • 領地をクリック → 詳細表示・アクション選択
  • ドラッグ → マップ移動
  • マウスホイール → ズーム

⚔️ 戦争

  • 自領地を選択 → 「出兵」ボタン → 隣接地をクリック
  • 兵力が多く、武将が強いほど勝率UP
  • 城の防御力も影響する

🏗️ 内政

  • 農業開発 → 人口増加
  • 商業開発 → 収入増加
  • 城強化 → 防御力UP
  • 町開発 → 全体的な発展

🤝 外交

  • 同盟 → 相手が攻撃されない・戦闘協力
  • 贈り物 → 関係改善（金100消費）
  • 休戦 → 一時停戦（4ターン）
